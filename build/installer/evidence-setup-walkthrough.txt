FG Scanner — How to set up and use the scanning station
=======================================================
For Jim's scanning computer (Portage County probate case).

This guide is written in small steps. Do them in order. Do not skip any.

After most steps it tells you WHAT YOU SHOULD SEE. If you do not see that,
stop and fix it before you go on. Do not keep going and hope.

Other papers on this stick:
    READ-ME-FIRST.txt   how to plug in the scanner and test it
    user-guide.md       the long manual, if you want more detail

WHY THIS GUIDE IS PICKY ABOUT SPELLING AND TICK BOXES

When you finish a box of paper, this program makes a folder. That folder goes
to Franz's computer. A program there reads it.

That program does not ask questions. If something is spelled wrong, it does
not show an error. It just leaves that part blank forever. Nobody finds out
until much later. Then the whole box has to be scanned again.

So: follow the steps exactly.


===============================================================================
PART 1 — Put the program on the computer
===============================================================================

STEP 1.1
    Read READ-ME-FIRST.txt. Install FG Scanner. Make sure the scanner works.
    Use the INSTALLER file, not the portable copy.

STEP 1.2
    Check the version number.

    Click Start. Type: Apps
    Open "Installed apps". Find "FG Scanner".

    WHAT YOU SHOULD SEE: 0.4.0 or a higher number.

    If it says 0.3.2 or lower, this is an old copy. Stop. Install the new one.
    An old copy makes folders that Franz's computer cannot read.

STEP 1.3
    Make a folder for the scans. Use the drive with the most free space.

    Example:   D:\Evidence-Scans\

    Make that folder now.

    HOW MUCH SPACE: about 1 GB for every 1,000 pages. Then double it, because
    the program keeps a spare copy of every page it changes. So plan on about
    2 GB per 1,000 pages.


===============================================================================
PART 2 — Turn on the important settings
===============================================================================

Open FG Scanner. Click "Settings".

Nothing saves until you press "Save profile & settings" at the bottom.
So do this whole part first, then press it once at the end.

STEP 2.1 — Keep the original picture (MOST IMPORTANT)

    Find the "OCR" area. Tick this box:

        [x] Keep an untouched copy of every image before its first edit
            (for evidence work)

    WHAT IT DOES: before the program ever changes a page, it saves a copy of
    the page exactly as it came off the scanner. That copy proves nothing was
    changed.

    WHY IT MATTERS: this only protects pages scanned AFTER you tick it. A page
    that was already changed has lost its first copy for good. Tick it before
    the first real sheet.

STEP 2.2 — Turn pages the right way up

    In the same "OCR" area, leave this ticked:

        [x] Turn misfed pages upright before reading them

    WHAT IT DOES: if a page goes through upside down, this turns it around.

    These two settings go together. Never turn this one on while Step 2.1 is
    off. If you did, every fix would erase the original picture.

STEP 2.3 — The Features area (near the bottom)

    Set them like this:

        [x] Blank-page policy            <- MUST be ticked
        [ ] Patch-T separator detection  <- leave empty
        [ ] Commit hook                  <- leave empty
        [x] Full-text search             <- ticked (helps you find pages later)

STEP 2.4 — Do not touch the AI part

    Leave the Gemini key box empty. Type nothing in it.

STEP 2.5 — Keep deleted pages longer

    Find "Keep deleted pages for". Change 30 days to 365 days.

    WHY: if you delete a page by mistake, you have a year to get it back
    instead of a month.

STEP 2.6
    Press "Save profile & settings".


===============================================================================
PART 3 — Make the Evidence profile (this is now ONE BUTTON)
===============================================================================

A "profile" is a saved list of the questions the program asks about each page.

IMPORTANT: You used to have to type thirteen field names by hand. You do not
anymore. Typing them by hand is now the WRONG way — one typo breaks the whole
pipeline quietly. There is a button that does it perfectly every time.

STEP 3.1
    Still in Settings, find the button that says:

        Build the Evidence profile

    Press it once.

    WHAT YOU SHOULD SEE: a profile named "Evidence" now exists in the profile
    list, and it has thirteen fields.

STEP 3.2
    Check the thirteen field names. Read them once and compare:

        DocNo        DocDate      DocType      Title
        Parties      Operator     Redact       Box
        Notes        NoteState    NoteAuthor   NoteBasis
        NoteWhen

    You do not need to type these. You are only checking the button worked.

STEP 3.3
    Make sure "Evidence" is the profile chosen in the dropdown box.
    Everything after this applies to the profile that is chosen.

STEP 3.4
    Find "Base folder for new groups". Press "Browse...".
    Pick the folder you made in Step 1.3 (example: D:\Evidence-Scans).

    WHY: now the program stops asking you where to save every single time.

STEP 3.5 — Turn on the two file types

    Find the index file formats. Tick exactly these:

        [x] CSV                 <- so a person can read it
        [ ] Excel (.xlsx)
        [ ] XML
        [x] JSON                <- FRANZ'S COMPUTER READS THIS ONE

    THE JSON TICK IS THE MOST IMPORTANT TICK ON THIS PAGE. It starts OFF.
    If you forget it, there is no file for Franz's computer to read, and the
    box has to be scanned again. Check it twice.

    Leave the CSV separator as a comma.

STEP 3.6 — OCR

        [x] Run OCR automatically on pages saved with this profile
        Languages:  eng

    OCR means the computer reads the words on the page so you can search them.

STEP 3.7 — Separator sheets

        [ ] Detect Patch-T separator sheets      <- leave EMPTY

    WHY: you mark where one document ends using the DocNo box, not with a
    special divider page. Leaving this off means no real page is ever mistaken
    for a divider and thrown away.

STEP 3.8 — Blank pages

        Blank pages:   Flag

    Pick "Flag". Do NOT pick "Drop".

    WHY: a blank back of a page is part of the record. It proves the back was
    blank. "Flag" keeps the page and just marks it. "Drop" throws it away.

STEP 3.9
    Press "Save profile & settings".


===============================================================================
PART 4 — Set up the scanner
===============================================================================

Click the "Scan" section. Set these:

    Driver:            TWAIN     (only use WIA if TWAIN cannot see the scanner)
    Device:            your scanner
    Source:            Feeder    (use Flatbed for torn or odd-sized paper)
    Resolution (DPI):  300
    Bit depth:         Color
    Page size:         Letter

ABOUT COLOR: always scan in Color, even for plain black text. Highlighter,
ink color and colored stamps are all evidence. Grey or black-and-white throws
that away and you cannot get it back.

ABOUT PAGE SIZE: the list is Letter, Legal, A4, A5, A3, B4, B5. There is no
"Auto". If your paper is not one of those, pick the next size BIGGER. A page
that gets cut off cannot be fixed without scanning it again.

Now scan one junk page to make sure it works.


===============================================================================
PART 5 — Test everything BEFORE real scanning
===============================================================================

Do not skip this part. It takes about five minutes. It is the only thing that
catches a mistake before it costs you two boxes of work.

STEP 5.1
    Go to "Groups". Make a new group. Name it:   setup-test

STEP 5.2
    Look at the top of the page area. You should see a panel that says:

        Batch values — answered once for this group, stamped on every row

    WHAT YOU SHOULD SEE inside it: a box for "Box" and a box for "Operator".
    "Operator" should already be filled in with your Windows user name.

    IF YOU DO NOT SEE THIS PANEL: the Evidence profile is not the one being
    used. Go back to Step 3.3.

STEP 5.3
    Type   test   into the "Box" line in that panel.

STEP 5.4
    Scan two junk pages into the group.

STEP 5.5
    Look at the page list.

    WHAT YOU SHOULD SEE: both rows already show   test   in the Box column,
    and your user name in the Operator column. You only typed it once.

STEP 5.6
    Try to click into the Box cell on one of the rows and change it.

    WHAT YOU SHOULD SEE: it will not let you type. That is correct. The Batch
    values panel at the top is the only place those are set.

STEP 5.7
    Fill in the rest for both pages. Put 1 in DocNo. Pick anything from the
    DocType dropdown.

    WHAT YOU SHOULD SEE: DocType is a dropdown list, not an empty typing box.
    It should offer 13 choices.

STEP 5.8
    Press Commit.

STEP 5.9
    Open File Explorer. Go to your scans folder, then into the setup-test
    folder.

    WHAT YOU SHOULD SEE — all three of these files:

        [ ] index.json
        [ ] index.csv
        [ ] manifest.json

STEP 5.10
    Double-click manifest.json. It opens in Notepad.

    Look for this line:

        "evidenceExport": 1

    IF IT IS NOT THERE: you are running an old version. Go back to Step 1.2.

STEP 5.11
    Double-click index.json. It opens in Notepad.

    Look at one page's section. Find these words:

        "sequence"          a number
        "pageId"            a long code
        "checksum"          a long code
        "isBlank"           says true or false
        "originalChecksum"  says null, or a long code
        "capturedBy"        should show your Windows user name

    Then find the "fields" part and check these names are spelled right:

        "DocNo"  "DocDate"  "DocType"  "Title"  "Parties"
        "Operator"  "Redact"  "Box"  "Notes"
        "NoteState"  "NoteAuthor"  "NoteBasis"  "NoteWhen"

    Also check that "Box" says   test   on every page.

STEP 5.12
    Go back into the group. Rotate one page.

    Then look in the group folder in File Explorer.

    WHAT YOU SHOULD SEE: a folder named   originals   with an untouched copy
    of that page inside.

    IF THAT FOLDER IS NOT THERE: go back to Step 2.1 and tick the box.

STEP 5.13
    Delete the setup-test group. Empty the Trash.

    Now you are ready to scan for real.


===============================================================================
PART 6 — How to scan a box of paper
===============================================================================

STEP 6.1 — One group for one box. Never mix two boxes.

    Name it plainly and never rename it later:

        loepp-box1
        loepp-box2

    The name becomes permanent in the case record.

STEP 6.2 — Fill in the paper card first

    Write down where the paper came from and the date you got it.
    The usual answers are:
        originals held = yes
        disposition = "originals remain boxed with Jim Tomaiko"

STEP 6.3 — COUNT THE SHEETS BY HAND

    Count the paper before you feed it. Write the number on the card.

    WHY: Franz's computer compares your hand count to how many pages arrived.
    That is how a page that jammed and never scanned gets noticed.

STEP 6.4 — Type the box number ONCE

    In the "Batch values" panel at the top, type the box number into "Box".

    Example:   box1        or      box1-folder03

    You type it one time for the whole box. Not on every page.
    "Operator" is already filled in. Leave it alone unless it is wrong.

STEP 6.5 — Scan in order

    Feed the paper in the order it sits in the box. Do not sort it.

STEP 6.6 — Mark where each document starts

    Put 1 in DocNo for the first document.

    When a NEW paper document starts, change DocNo to 2. Then 3. And so on.

    Pages with the same DocNo are treated as one document.

STEP 6.7 — Fill in what you can see on the page

    DocDate    the date printed on the paper. If there is none, leave it blank.
               NEVER GUESS A DATE.
    DocType    pick from the dropdown
    Title      what the paper is called
    Parties    the people or companies named on it
    Redact     ONLY if you can see an account number, a Social Security
               number, a password, or medical information.
                   identifier = account number, SSN, password
                   phi        = medical information

    RULE FOR REDACT: say WHERE it is. Never type the actual number anywhere.

STEP 6.8 — SCAN EVERYTHING

    Scan every sheet. Do not hold anything back.

    Not duplicates. Not blank pages. Not odd ones. Not embarrassing ones.

    If a page is strange, write about it in "Notes". Do not put it in a
    separate pile.

STEP 6.9 — Do not fix pages

    Do not rotate, crop, or delete pages. If a page feeds badly, write it in
    Notes and scan that sheet again as an extra page. Someone will sort it out
    later.


===============================================================================
PART 7 — Sheets that have sticky notes on them
===============================================================================

A sheet with a sticky note stuck to it is TWO pieces of evidence: the note,
and the paper under it. So it gets scanned more than once.

DO NOT peel the note off and scan just the paper. That destroys the record of
where the note was sitting.

The program walks you through it. Just read the words on the screen.

STEP 7.1
    Put the sheet in with the note still stuck on it.

STEP 7.2
    Press   Ctrl+Shift+N
    (or click the button that says "Sheet with notes")

STEP 7.3
    The screen will say:

        "Notes in place — scan the sheet exactly as you found it."

    Scan it just like that, note and all.

STEP 7.4
    The screen will say:

        "Scan the lifted note on its own."

    Peel the note off. Scan just the note by itself.

    (If there is no separate note to scan, skip to the next screen.)

STEP 7.5
    The screen will say:

        "Lift every note, then Scan the sheet clean. Put the notes back
         afterwards."

    Scan the bare paper. Then stick the notes back where they were.

STEP 7.6
    Answer these three about the note, if you know:

        NoteAuthor   who wrote it. If you do not know, type:  unknown
        NoteBasis    how you know who wrote it:
                         stated       — it is signed or says who
                         handwriting  — you recognize the writing
                         signed       — it is signed
                         none         — you do not know
        NoteWhen     when it was written. If you do not know, type: unknown

    "unknown" IS A GOOD ANSWER. Never guess. A guess in an evidence file is
    worse than an empty box.

IF YOU START A NOTE SHEET BY MISTAKE:
    Press the Cancel button on the screen. It throws away the half-finished
    sheet. Then start over.

    IMPORTANT: never leave a note sheet half done. If you scan the "as found"
    picture but never scan the clean one, Franz's computer REFUSES THE WHOLE
    BOX. Finish the sheet or cancel it.


===============================================================================
PART 8 — Finishing a box and sending it to Franz
===============================================================================

STEP 8.1 — Look over the pages

    Scroll the list. Look for pages marked as blank. Make sure they really are
    blank and not just very faint.

STEP 8.2 — Press Commit

    The program checks your work first. It will stop you if DocNo, Operator or
    Box is missing.

    IF IT COMPLAINS about a missing Box: that message shows up ONCE at the top
    now, not on every single page. Fill in the Batch values panel and try again.

STEP 8.3 — Copy the folder

    Open File Explorer. Find the group folder (example: D:\Evidence-Scans\
    loepp-box1).

    Copy THE WHOLE FOLDER to the transfer drive.

    MAKE SURE the copy includes the   originals   folder inside it. That folder
    is part of the evidence. A copy without it is not complete.

STEP 8.4 — Then leave it alone

    After you copy it, DO NOT go back and change any field in that group.

    WHY: changing a field after Commit quietly rewrites the index files. The
    copy you already handed over would no longer match. Nothing warns you.

STEP 8.5 — Tell Franz

    Tell Franz:
        - the group name (example: loepp-box1)
        - your hand count of the sheets
        - where the paper came from and the date you got it

    Franz runs the import on his computer. You do not run anything.


===============================================================================
PART 9 — Things that break QUIETLY (no error message)
===============================================================================

Every one of these gives you NO warning. That is why they are listed.

  * JSON not ticked (Step 3.5). No file for Franz. The box must be redone.

  * Typing the thirteen field names by hand instead of pressing the button
    (Part 3). One typo makes that column import empty, forever.

  * Blank pages set to "Drop" instead of "Flag". Pages disappear.

  * "Keep an untouched copy" left off (Step 2.1). Every fix destroys the
    original picture permanently.

  * Changing a field after you committed and copied. The handed-over copy goes
    stale and no longer matches.

  * Renaming a group after scanning. The name is permanent.

  * Forgetting the   originals   folder when you copy (Step 8.3).

  * Leaving a sticky-note sheet half finished (Part 7). Franz's computer
    refuses the whole box.

  * Running version 0.3.2 or older. Check manifest.json for "evidenceExport".

IF SOMETHING GOES WRONG, the log files are here:

    %LOCALAPPDATA%\FGScanner\logs\

Your work lives in two places. Back up BOTH:

    %APPDATA%\FGScanner        the database and the trash
    D:\Evidence-Scans          the actual scan folders
